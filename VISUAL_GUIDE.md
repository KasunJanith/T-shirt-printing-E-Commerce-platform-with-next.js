## 🎨 DESIGN SYSTEM

### Color Palette
```
Primary:   Blue (#2563eb) → Purple (#9333ea) → Pink (#ec4899)
Secondary: Gray shades (#f9fafb to #1f2937)
Accent:    Yellow (#fbbf24), Green (#10b981), Red (#ef4444)
```

### Typography
```
Headings:  Inter, Bold, 2xl-6xl
Body:      Inter, Regular, sm-lg
Captions:  Inter, Medium, xs-sm
```

### Spacing
```
Cards:     p-6 (24px padding)
Gaps:      gap-4 to gap-8 (16px-32px)
Margins:   mb-4 to mb-12 (16px-48px)
```

### Shadows
```
Card:      shadow-md (medium elevation)
Hover:     shadow-lg (large elevation)
Modal:     shadow-2xl (extra large)
```

### Border Radius
```
Buttons:   rounded-lg (8px)
Cards:     rounded-xl (12px)
Inputs:    rounded-md (6px)
Badges:    rounded-full (9999px)
```

### Animations
```
Hover:     transition-all duration-200
Modal:     animate-fade-in
Success:   animate-scale-in
Loading:   animate-spin
```
