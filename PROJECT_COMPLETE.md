## 🔧 HOW TO RUN

```bash
# 1. Install dependencies
npm install

# 2. Set up environment variables
# Create .env file with:
# - DATABASE_URL
# - NEXTAUTH_SECRET
# - NEXTAUTH_URL

# 3. Set up database
npx prisma generate
npx prisma migrate dev

# 4. Start development server
npm run dev

# 5. Visit http://localhost:3000
```
